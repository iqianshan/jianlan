简览的第一个正式版。解压即用，不需要安装、不需要管理员权限、不需要预装 .NET。

1.0 的意思是**功能面冻结**：需求里的 P0、P1 全部落地，后续版本不再加功能，只做验收补跑与打磨。

## 这一版能做什么

- **双窗格 + 多标签**：`F3` 左右并排，两个目录之间直接拖；标签可关、可恢复、可在新窗口打开。
- **彩色标记**：一个文件可打多种颜色，侧栏按颜色汇总，`Alt+1…8` 一键上色。
- **收藏与工作区**：常用目录钉在侧栏；把当前一组标签存成工作区，下次一键还原。
- **预览**：选中按 `Space` 盖一层快速预览（不抢焦点、方向键可继续翻），`Alt+P` 开常驻预览窗格。
- **完整键盘操作**：全流程可只用键盘；**所有键位都能在设置里改**，还能解绑、恢复默认。
- **全局唤起键**：可设一个系统级热键，在别的程序前台时把窗口叫到面前；已在前台时再按是收起。
- **安全一点的打开方式**：可选「打开可执行文件前先确认」，双击、回车、拖入、从收藏打开四个入口统一生效。

## 下载

`Jianlan-1.0.0-portable-win-x64.zip`（70.7 MB，展开 182.8 MB）

SHA256：`5d9532a9bcecb7da65717506110062bb3c8835f6ce164e5a4c85b0ed1798bb1e`

解压到任意有写权限的目录（不建议 `C:\Program Files`，便携模式要把设置写在程序旁边），双击
`Jianlan.exe`。卸载就是删掉整个目录——不写注册表、不装服务、不开机自启。

校验：

```powershell
Get-FileHash .\Jianlan-1.0.0-portable-win-x64.zip -Algorithm SHA256
```

同目录的 `.sha256` 是对应值。

## 从旧版本升级

新版压缩包**不含** `data\`，所以把新包覆盖解压到原目录不会丢收藏、工作区与标签。升级前确认：
所有副本（包括别的盘上的）都已完全退出、不要带着运行中的 `session.json` 拷贝 `data\`。
完整步骤见 README 的「升级到新版本」。

确认升级成功：设置 → 关于，版本号形如 `1.0.0+<提交号>`。

## 已知限制

功能上值得先知道的几条：

- 大文件复制/移动**没有进度条与取消**，只有状态栏一行提示。
- **没有大图标/磁贴视图**，只有详细信息与列表。
- 一行最多显示**三个色点**，第四色起只在侧栏计数与菜单里体现。
- 收藏、工作区暂不支持**一键导入导出**（标签库支持）。
- 地址栏**只认目录**，输入文件路径不会打开它。

验收上未跑完的三项，本版**不作承诺**：Windows 10 兼容性（只在 Win11 实测）、8 小时长跑的完整
时长（最近一轮受控场景 156 分钟 0 崩溃、未跑满 480 分钟）、断网全流程走查（程序本身不发起任何
网络请求）。逐条缺口见 `CHANGELOG.md` 的「1.0 已知限制」。
