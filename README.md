一个更轻、更顺手的 Windows 文件管理器。解压就能用，不用安装。

资源管理器的窗口开了一排，跨盘搬文件要来回切；上次处理到一半的那批文件，第二天找回来又要重新点一遍。
简览就为这些场景做：**双窗格并排看、多标签装下所有目录、彩色标记记住进度、关闭后原样回来**。

当前版本 **0.2.1**，界面支持简体中文与英文。

---

## 为什么用它

| 你会遇到的麻烦 | 简览怎么解决 |
|---|---|
| 开一堆窗口，切来切去分不清 | 一个窗口开多个标签，标签可关可恢复、可在新窗口打开 |
| 两个目录之间搬东西，来回跳 | `F3` 开双窗格，左右并排，直接拖；两边各自记住自己的视图与排序 |
| 文件处理到一半，第二天忘了哪几个 | 给文件打彩色标记，同一文件可打多种色，侧栏按颜色汇总 |
| 想直接看一眼图片/文档/视频 | `Alt+P` 开预览窗格，图片、文本、PDF、Office、音视频都不用打开程序 |
| 手滑改名或删错 | `Ctrl+Z` 撤回上一步：改名改回去、删除从回收站还原 |
| 打开软件要等好几秒 | 冷启动约 0.7 秒；万项目录滚动不卡顿 |

## 下载与安装

1. 到 **Releases** 下载 `Jianlan-0.2.1-portable-win-x64.zip`（约 70 MB）。
2. 解压到任意你有写权限的目录，例如 `D:\Tools\Jianlan`。
   **不建议放进 `C:\Program Files`**——便携模式要把设置写在程序旁边。
3. 双击 `Jianlan.exe` 即可使用。

不需要安装，不需要管理员权限，**不需要预先安装 .NET**（运行时已打包在压缩包里）。

想确认文件完整，可对照同目录的 `.sha256` 校验值：

```powershell
Get-FileHash .\Jianlan-0.2.1-portable-win-x64.zip -Algorithm SHA256
```

**卸载**：关掉程序，删除整个解压目录即可。程序不写注册表、不装服务、不开机自启。

### 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / Windows 11，64 位（已在 Windows 11 上完整验证） |
| 内存 | 4 GB 以上；程序自身占约 130–170 MB |
| 磁盘 | 约 190 MB（解压后） |
| 权限 | 普通用户即可；以管理员运行可访问受保护目录 |

## 第一次打开

启动后第一个标签就是**主页**，四块内容：常用目录、驱动器、最近访问、收藏。点任何一块直接进去。

建议按这个顺序熟悉（大约五分钟）：

1. **开双窗格**：按 `F3`，左边选源目录，右边选目的目录，把文件拖过去。
2. **打标记**：选中文件右键 →「标签」→ 选一个颜色；行首出现色点，侧栏「标签」里能按色找到它们。
3. **收藏**：`Ctrl+D` 收藏当前目录或选中项，之后在主页和侧栏一点就到。
4. **存一组标签**：把正在用的几个目录开成标签，在主页「工作区」里点「保存当前标签…」（或右键侧栏的「工作区」标题），
   下次整组恢复，包括分屏和固定状态。
5. **关掉再打开**：窗口大小、标签、分屏比例、列宽都会原样回来。

### 界面分四块

| 区域 | 里面有什么 |
|---|---|
| 标签栏（顶部） | 每个标签是一个目录；`＋` 新建，右键有固定、关闭其他、在新窗口打开 |
| 侧栏（左侧） | 常用目录、此电脑（逐盘显示剩余空间）、收藏、标签、回收站与网络；宽度可拖，双击复位 |
| 中间主体 | 工具栏（前进/后退/上级/刷新、面包屑地址栏、搜索、视图切换）+ 文件列表 + 状态栏 |
| 预览窗格（右侧，`Alt+P`） | 图片、文本、代码、PDF、Office、音视频；选中单个文件时可打开、复制路径、删除 |

## 常用操作

只列**键盘上真能用**的组合；鼠标操作写在后面。

### 浏览与导航

| 操作 | 快捷键 |
|---|---|
| 后退 / 前进 / 上一级 | `Alt+←` / `Alt+→` / `Alt+↑`（或 `Backspace`） |
| 跳到地址栏输入路径 | `Ctrl+L`（有自动补全，`Tab` 补全、`Enter` 打开） |
| 在当前目录搜索 | `Ctrl+F`，`Esc` 清空 |
| 刷新 | `F5` 或 `Ctrl+R` |
| 收藏当前目录 / 选中项 | `Ctrl+D` |
| 鼠标侧键 | 后退 / 前进 |

### 标签页

| 操作 | 快捷键 |
|---|---|
| 新建 / 关闭 / 恢复刚关的 | `Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T` |
| 切到下一个 / 上一个 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 跳到第 N 个 / 最后一个 | `Ctrl+1…8` / `Ctrl+9` |

鼠标：中键点标签=关闭，拖动=换顺序，右键=固定、关闭其他、复制路径、在新窗口打开。
中键点文件夹、或 `Ctrl+点文件夹`，会在新标签打开。

### 文件操作

| 操作 | 快捷键 |
|---|---|
| 打开 | `Enter` |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 重命名 | `F2`；也可以**再点一次文件名**（该行已选中时） |
| 新建文件夹 / 新建文本文档 | `Ctrl+Shift+N` / `Ctrl+Shift+M` |
| 删除到回收站 / 永久删除 | `Delete` / `Shift+Delete` |
| 撤销上一步 | `Ctrl+Z` |
| 复制完整路径 | `Ctrl+Shift+C` |
| 属性 | `Alt+Enter` |
| 全选 | `Ctrl+A` |

改名就在列表里原地进行，不弹对话框。进入时只选中扩展名之前那一段（`报告.docx` 选中「报告」，
文件夹整名选中），`Enter` 确认后仍停在这一行；`Esc` 放弃；点别处等同于确认。
名字不合法或与现有文件重名时不会退出，输入框描红，直接重敲即可覆盖。
新建文件夹 / 新建文本文档之后会直接进入改名状态。

拖放：拖入默认同盘移动、跨盘复制；按住 `Ctrl` 强制复制、`Shift` 强制移动；拖到某个文件夹行上=放进该文件夹；拖出到其它程序=交给对方打开。

### 视图与面板

| 操作 | 快捷键 |
|---|---|
| 详细信息 / 列表视图 | `Ctrl+Shift+1` / `Ctrl+Shift+2` |
| 切换主题（跟随系统→浅色→深色→高对比度） | `Ctrl+Shift+D` |
| 双窗格开关 | `F3`（或 `Ctrl+Shift+E`） |
| 两窗格间切焦点 | `Tab` 或 `F6` |
| 预览窗格开关 | `Alt+P`（或 `Ctrl+Shift+P`） |
| 设置 | `Ctrl+,` |

## 它还能做什么

- **标签**：默认八色，可改名（把「红」改成「紧急」）、可增删（最多 32 个）；标签库能导出成 JSON 带走。
- **收藏**：拖进去就收藏，可分组、改名、换图标与颜色、拖拽排序；失效项灰显并可批量清理。
- **工作区**：把当前这组标签（含分屏另一半、固定标记）存成一份，随时整组恢复。最多 50 个。
- **搜索**：边输边过滤，目录再大也不卡；显示匹配数与总数，超出上限会明说。
- **文件夹大小**：右键「计算文件夹大小」才计算，可随时 `Esc` 中止。
- **缩略图**：图片与视频在行内显示真实画面，有磁盘缓存，可清可限容。
- **列配置**：四列可显隐、换序、改宽，不同类型的目录分别记忆。
- **多窗口**：标签右键「在新窗口打开」，两个窗口互不影响，关掉一个另一个照常。
- **单实例**：重复双击只会把路径交给已开的窗口，不会多起一个。也可以把文件夹拖到 `Jianlan.exe` 上直接打开。
- **异常恢复**：上次异常退出，下次启动会提示并给出日志导出入口（关于页可一键打包日志 zip）。

## 设置里有什么

`Ctrl+,` 打开，左侧七页：

| 页 | 主要内容 |
|---|---|
| 常规 | 界面语言（跟随系统 / 简体中文 / English）、启动行为、新标签默认目录 |
| 外观 | 主题（浅色 / 深色 / 跟随系统 / 高对比度）、强调色、字体与字号（8–24pt）、界面密度、导航栏与状态栏开关 |
| 文件列表 | 默认视图与排序、显示隐藏文件、显示扩展名、单击打开、缩略图缓存 |
| 操作与确认 | 删除确认、批量删除确认、覆盖确认、打开可执行文件前确认 |
| 隐私与存储 | 清空历史、标签库导入导出与统计、隐私声明、分类恢复默认 |
| 标签 | 八种颜色的名称与颜色值 |
| 关于 | 版本、更新检查、日志导出、许可证 |

## 数据存在哪里

设置、历史、收藏、标签、工作区全部存在**本机**，不上传。

| 运行方式 | 数据位置 |
|---|---|
| 便携包（官方 zip，解压即用） | 程序目录下的 `data\` |
| 自行从源码构建、未开启便携模式 | `%LOCALAPPDATA%\Jianlan` |

`data\` 里主要是 `settings.json`（设置）与 `logs\`（运行日志）。
**换机器或备份时，整个 `data\` 目录拷走即可**；删掉它就等于恢复出厂设置。

**隐私**：不收集遥测，不上传任何数据，程序本身不发起网络请求。唯一的对外动作是你手动点「检查更新」时用系统浏览器打开发布页。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

**任务栏图标是一张白卡片？**
0.2.1 已修复这个问题。若仍出现，先确认用的是 0.2.1 及以后的包——旧的解压目录和系统里的图标缓存都可能还是老样子，换一个新目录重新解压再试。

**双击没反应 / 被安全软件拦了？**
本程序无数字签名，部分安全软件会对未签名的新程序提示。确认来源是本仓库 Releases 后放行即可；也可先用 `.sha256` 校验文件完整性。

**删除为什么进了回收站？**
这是默认行为，为了能撤销。要彻底删除用 `Shift+Delete`（会二次确认）。

**`Ctrl+,` 打不开设置？**
中文输入法有时会截走标点组合。可改用菜单里的「设置」，或先切到英文输入状态。

**复制几个 GB 的大文件，只有「正在复制…」没有进度条？**
当前版本确实没有传输进度窗与取消按钮，已在后续需求中排期。复制期间建议不要重复触发粘贴。

**会改我的文件关联吗？**
不会。程序不注册文件类型、不接管右键菜单，只在「更多选项…」里调用系统自带菜单。

**支持 Windows 7 / macOS 吗？**
当前只做 Windows 10/11 64 位。跨平台移植的接口划分与操作对照已写进需求规格说明书，供后续开发其它系统版本使用。

## 已知限制（0.2.1）

- 大文件复制/移动**没有进度条与取消**，只有状态栏一行提示。
- **没有大图标/磁贴视图**，只做详细信息与列表两种。
- 一行最多显示**三个色点**；第四种及以后的颜色仍会被记录、侧栏也计入，只是行上看不到。
- 标签、收藏、工作区暂不支持**一键全部导出/导入**（标签库已支持）。
- Windows 10 兼容性、8 小时稳定性、断网场景三项验收未跑完，本版不对相应指标作承诺。

更细的取舍与原因见 [CHANGELOG.md](CHANGELOG.md) 与 [docs/backlog.md](docs/backlog.md)。
