一个更轻、更顺手的 Windows 文件管理器。解压就能用，不用安装。

资源管理器的窗口开了一排，跨盘搬文件要来回切；上次处理到一半的那批文件，第二天找回来又要重新点一遍。
简览就为这些场景做：**双窗格并排看、多标签装下所有目录、彩色标记记住进度、关闭后原样回来**。

当前版本 **1.0.0**，界面支持简体中文与英文。1.0 表示**功能面冻结**：需求里的 P0、P1 全部落地，
后续版本只做验收补跑与局部打磨。

---

## 为什么用它

| 你会遇到的麻烦 | 简览怎么解决 |
|---|---|
| 开一堆窗口，切来切去分不清 | 一个窗口开多个标签，标签可关可恢复、可在新窗口打开 |
| 两个目录之间搬东西，来回跳 | `F3` 开双窗格，左右并排，直接拖；两边各自记住自己的视图与排序 |
| 文件处理到一半，第二天忘了哪几个 | 给文件打彩色标记，同一文件可打多种色，侧栏按颜色汇总 |
| 想直接看一眼图片/文档/视频 | 选中文件按 `Space` 盖一块预览（不抢焦点，方向键可继续翻页）；要常驻一栏就 `Alt+P` 开预览窗格 |
| 手滑改名或删错 | `Ctrl+Z` 撤回上一步：改名改回去、删除从回收站还原 |
| 打开软件要等好几秒 | 冷启动约 0.7 秒；万项目录滚动不卡顿 |

## 下载与安装

1. 到 **Releases** 下载 `Jianlan-1.0.0-portable-win-x64.zip`（约 70 MB）。
2. 解压到任意你有写权限的目录，例如 `D:\Tools\Jianlan`。
   **不建议放进 `C:\Program Files`**——便携模式要把设置写在程序旁边。
3. 双击 `Jianlan.exe` 即可使用。

不需要安装，不需要管理员权限，**不需要预先安装 .NET**（运行时已打包在压缩包里）。

想确认文件完整，可对照同目录的 `.sha256` 校验值：

```powershell
Get-FileHash .\Jianlan-1.0.0-portable-win-x64.zip -Algorithm SHA256
```

**卸载**：关掉程序，删除整个解压目录即可。程序不写注册表、不装服务、不开机自启。

**已经在用旧版本？** 把新包覆盖解压到原目录即可，收藏、工作区、标签都在 `data\` 里、不受影响——
做法与注意事项见[升级到新版本](#升级到新版本)。

### 系统要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / Windows 11，64 位（已在 Windows 11 上完整验证） |
| 内存 | 4 GB 以上；程序自身占约 130–170 MB |
| 磁盘 | 约 190 MB（解压后） |
| 权限 | 普通用户即可；以管理员运行可访问受保护目录 |

## 升级到新版本

### 一句话原则

你的全部个人数据只在程序目录的 `data\` 里，而新版本的压缩包**不含** `data\`。所以"用新版覆盖
旧版"本身不会丢设置——**只要不动那个目录**。包里还带着 `portable.flag`，覆盖后仍是便携模式。

`data\` 里具体有哪些文件，见[数据存在哪里](#数据存在哪里)。

### 做法一：直接覆盖（最省事）

适用于补丁版本之间（如 `1.0.0` → `1.0.1`），或者你只想换个新目录、旧目录随手留着。

1. **完全退出**简览。托盘图标要退；**放在别的盘、别的目录的副本也要退**——程序是单实例的，
   只要还有一份在跑，新启动的那份会立即退出并把参数转交给它，看起来像"双击没反应"。
2. 把新 zip 里的文件解压到旧目录，同名文件选「替换」。
3. 启动。收藏、工作区、标签、上次打开的标签页与窗口位置都在。

### 做法二：先备份、再换目录（更稳）

适用于跨大版本（如 `0.2.1` → `1.0.0`），或者想连旧版本残留的无用文件一起清掉。

1. 把旧目录的 `data\` 整个拷到别处。**只拷 `settings.json` 不够**——工作区在
   `workspaces.json`，标签库在 `data\tags.jsonl`。
2. 清空旧目录。
3. 把新 zip 解压到原位置。
4. 把备份的 `data\` 拷回去。

这两步不要交给脚本或"一键替换"工具去做。它们会动程序目录本身，出错的位置与后果你事先
看不见；而上面几步在资源管理器里手工做，改了什么、删了什么，每一步都在眼前。

### 升级前的四条检查

| 检查 | 为什么 |
|---|---|
| 所有副本都退出了 | 单实例互斥体是全局的，另一份在跑会让新的那份直接退出 |
| 没有在程序运行时拷 `data\` | 会把 `session.json` 一起带走，新版本首启显示「上次没有正常结束」的提示条；删掉该文件即可，它不含设置 |
| 备份的是整个 `data\` | 只备份 `settings.json` 会漏掉工作区与标签库 |
| 安装位置不变 | 原地覆盖，桌面快捷方式与固定到任务栏的项都照旧可用 |

### 怎么确认升级成功

启动后打开「设置 → 关于」，版本号形如 `1.0.0+<提交号>`（主版本 + 构建提交号）。再看一眼收藏、工作区是否都在、上次打开的标签页是否回来，就可以把备份删掉了。

## 第一次打开

启动后第一个标签就是**主页**，四块内容：常用目录、驱动器、最近访问、收藏。点任何一块直接进去。

建议按这个顺序熟悉（大约五分钟）：

1. **开双窗格**：按 `F3`，左边选源目录，右边选目的目录，把文件拖过去。
2. **打标记**：选中文件右键 →「标签」→ 选一个颜色；行首出现色点，侧栏「标签」里能按色找到它们。
3. **收藏**：`Ctrl+D` 收藏当前目录或选中项，之后在主页和侧栏一点就到。
4. **存一组标签**：把正在用的几个目录开成标签，在主页「工作区」里点「保存当前标签…」（或右键侧栏的「工作区」标题），
   下次整组恢复，包括分屏和固定状态。
5. **关掉再打开**：窗口大小、标签、分屏比例、列宽都会原样回来。

### 界面分四块

| 区域 | 里面有什么 |
|---|---|
| 标签栏（顶部） | 每个标签是一个目录；`＋` 新建，右键有固定、关闭其他、在新窗口打开 |
| 侧栏（左侧） | 常用目录、此电脑（逐盘显示剩余空间）、收藏、标签、回收站与网络；宽度可拖，双击复位 |
| 中间主体 | 工具栏（前进/后退/上级/刷新、面包屑地址栏、搜索、视图切换）+ 文件列表 + 状态栏 |
| 预览窗格（右侧，`Alt+P`） | 图片、文本、代码、PDF、Office、音视频；选中单个文件时可打开、复制路径、删除 |
| 空格预览浮层（`Space`） | 盖在列表上的一块预览，不抢焦点，方向键可继续翻页；点任意处、再按 `Space` 或 `Esc` 收起 |

## 常用操作

只列**键盘上真能用**的组合；鼠标操作写在后面。

### 浏览与导航

| 操作 | 快捷键 |
|---|---|
| 后退 / 前进 / 上一级 | `Alt+←` / `Alt+→` / `Alt+↑`（或 `Backspace`） |
| 跳到地址栏输入路径 | `Ctrl+L`（有自动补全，`Tab` 补全、`Enter` 打开） |
| 在当前目录搜索 | `Ctrl+F`，`Esc` 清空 |
| 刷新 | `F5` 或 `Ctrl+R` |
| 收藏当前目录 / 选中项 | `Ctrl+D` |
| 鼠标侧键 | 后退 / 前进 |

### 标签页

| 操作 | 快捷键 |
|---|---|
| 新建 / 关闭 / 恢复刚关的 | `Ctrl+T` / `Ctrl+W` / `Ctrl+Shift+T` |
| 切到下一个 / 上一个 | `Ctrl+Tab` / `Ctrl+Shift+Tab` |
| 跳到第 N 个 / 最后一个 | `Ctrl+1…8` / `Ctrl+9` |

鼠标：中键点标签=关闭，拖动=换顺序，右键=固定、关闭其他、复制路径、在新窗口打开。
中键点文件夹、或 `Ctrl+点文件夹`，会在新标签打开。

### 文件操作

| 操作 | 快捷键 |
|---|---|
| 打开 | `Enter` |
| 复制 / 剪切 / 粘贴 | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| 重命名 | `F2`；也可以**再点一次文件名**（该行已选中时，等半秒确认不是双击才进入） |
| 新建文件夹 / 新建文本文档 | `Ctrl+Shift+N` / `Ctrl+Shift+M` |
| 删除到回收站 / 永久删除 | `Delete` / `Shift+Delete` |
| 撤销上一步 | `Ctrl+Z` |
| 复制完整路径 | `Ctrl+Shift+C` |
| 属性 | `Alt+Enter` |
| 全选 | `Ctrl+A` |
| 反选 | `Ctrl+Shift+A` |

改名就在列表里原地进行，不弹对话框。进入时只选中扩展名之前那一段（`报告.docx` 选中「报告」，
文件夹整名选中），`Enter` 确认后仍停在这一行。**只有 `Enter` 会改名字**——`Esc`、点列表空白、
点别的行、点工具栏或侧栏、切标签、换目录、把这一行滚出视野，都按放弃处理，磁盘一个字都不动。
刚进编辑时 `←` `↑` 跳到最左、`→` `↓` 跳到最右；动过之后（敲了字、点过输入框、或已经按过
一次方向键）就变成逐字移动。
改了扩展名要先确认：`.docx` 改成 `.md` 之后文件多半打不开，所以按 `Enter` 时会先问一句，
点「是」才真改，点「否」留在原处、名字也留着让你接着改。
名字不合法或与现有文件重名时不会退出，输入框描红，直接重敲即可覆盖。
新建文件夹 / 新建文本文档之后会直接进入改名状态。

拖放：拖入默认同盘移动、跨盘复制；按住 `Ctrl` 强制复制、`Shift` 强制移动；拖到某个文件夹行上=放进该文件夹；拖出到其它程序=交给对方打开。

剪贴板：`Ctrl+C` / `Ctrl+X` 复制的东西在**系统剪贴板**里，可以直接到资源管理器里 `Ctrl+V`；
反过来在资源管理器里复制的文件也能粘进来。剪切是"到对方粘贴即移动"，不是先删后拷。
关掉简览再粘贴也没问题——内容在复制那一刻就已经交出去了。

### 视图、工作区与应用

| 操作 | 快捷键 |
|---|---|
| 详细信息 / 列表视图 | `Ctrl+Shift+1` / `Ctrl+Shift+2` |
| 切换主题（跟随系统→浅色→深色→高对比度） | `Ctrl+Shift+D` |
| 双窗格开关 | `F3`（或 `Ctrl+Shift+E`） |
| 两窗格间切焦点 | `Tab` 或 `F6` |
| 预览窗格开关 | `Alt+P`（或 `Ctrl+Shift+P`） |
| 空格预览（选中文件后按一下，再按收起） | `Space`（`Esc` 也可收起） |
| 侧边导航栏开关 | `Ctrl+B` |
| 显示/隐藏隐藏文件 | `Ctrl+Shift+H` |
| 侧栏「历史」分区开关 | `Ctrl+H` |
| 设置 | `Ctrl+,` |
| 全部快捷键一览 | `F1`（直接翻到设置里的「快捷键」页） |
| 把当前标签保存为工作区 | `Ctrl+Alt+S`（弹窗起个名字） |
| 打开工作区列表 | `Ctrl+Alt+O`（切到主页的工作区卡片区） |
| 退出 | `Alt+F4` 或 `Ctrl+Q` |

**快捷键可以改**。`F1` 或设置 →「快捷键」列出全部命令：点「修改」，然后按下想用的组合；
按 `Delete` 清空即解绑，点「恢复默认」回到出厂键位。改完立刻生效，不用重启。
备用键位（例如刷新除 `F5` 外的 `Ctrl+R`）是固定的第二入口，只读显示。

顺手的话还可以在那里给程序**设一个全局唤起键**（默认关闭）：在别的程序里按一下就把窗口
叫到面前，窗口已经在前台时再按是收起。它只在程序运行期间有效，不写注册表、不设开机自启、
不常驻后台。这个键可以用 `Win` 组合（例如 `Win+Shift+F9`），窗口内的命令则不行——
系统会先处理那些组合，按下去多半没反应。

## 它还能做什么

- **标签**：默认八色，可改名（把「红」改成「紧急」）、可增删（最多 32 个）；标签库能导出成 JSON 带走。
- **收藏**：拖进去就收藏，可分组、改名、换图标与颜色、拖拽排序；失效项灰显并可批量清理。
- **工作区**：把当前这组标签（含分屏另一半、固定标记）存成一份，随时整组恢复。最多 50 个。
- **搜索**：边输边过滤，目录再大也不卡；显示匹配数与总数，超出上限会明说。
- **文件夹大小**：右键「计算文件夹大小」才计算，可随时 `Esc` 中止。
- **缩略图**：图片与视频在行内显示真实画面，有磁盘缓存，可清可限容。
- **列配置**：四列可显隐、换序、改宽，不同类型的目录分别记忆。
- **多窗口**：标签右键「在新窗口打开」，两个窗口互不影响，关掉一个另一个照常。
- **单实例**：重复双击只会把路径交给已开的窗口，不会多起一个。也可以把文件夹拖到 `Jianlan.exe` 上直接打开。
- **异常恢复**：上次异常退出，下次启动会提示并给出日志导出入口（关于页可一键打包日志 zip）。

## 数据存在哪里

设置、历史、收藏、标签、工作区全部存在**本机**，不上传。

| 运行方式 | 数据位置 |
|---|---|
| 便携包（官方 zip，解压即用） | 程序目录下的 `data\` |
| 自行从源码构建、未开启便携模式 | `%LOCALAPPDATA%\Jianlan` |

`data\` 里放的是这些：

| 文件 | 内容 |
|---|---|
| `settings.json` | 设置、收藏、历史、上次的标签页与窗口位置 |
| `workspaces.json` | 工作区 |
| `data\tags.jsonl` | 彩色标签库 |
| `session.json` | "上次是否干净退出"的标记，自动生成、正常退出时删掉；不含设置 |
| `logs\` | 运行日志（不含任何路径以外的个人信息） |

**换机器或备份时，整个 `data\` 目录拷走即可**；删掉它就等于恢复出厂设置。升级新版本时同理——
不要覆盖或删除 `data\`，见上文「升级到新版本」。

**隐私**：不收集遥测，不上传任何数据，程序本身不发起网络请求。唯一的对外动作是你手动点「检查更新」时用系统浏览器打开发布页。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

**任务栏图标是一张白卡片？**
1.0 已修复这个问题。若仍出现，先确认用的是 1.0 及以后的包——旧的解压目录和系统里的图标缓存都可能还是老样子，换一个新目录重新解压再试。

**双击没反应 / 被安全软件拦了？**
本程序无数字签名，部分安全软件会对未签名的新程序提示。确认来源是本仓库 Releases 后放行即可；也可先用 `.sha256` 校验文件完整性。

**删除为什么进了回收站？**
这是默认行为，为了能撤销。要彻底删除用 `Shift+Delete`（会二次确认）。

**`Ctrl+,` 打不开设置？**
中文输入法有时会截走标点组合。可改用菜单里的「设置」，或先切到英文输入状态。

**复制几个 GB 的大文件，只有「正在复制…」没有进度条？**
当前版本确实没有传输进度窗与取消按钮，已在后续需求中排期。复制期间建议不要重复触发粘贴。

**会改我的文件关联吗？**
不会。程序不注册文件类型、不接管右键菜单，只在「更多选项…」里调用系统自带菜单。

**支持 Windows 7 / macOS 吗？**
当前只做 Windows 10/11 64 位。跨平台移植的接口划分与操作对照已写进需求规格说明书，供后续开发其它系统版本使用。

## 已知限制（1.0）

- 大文件复制/移动**没有进度条与取消**，只有状态栏一行提示。
- **没有大图标/磁贴视图**，只做详细信息与列表两种。
- 一行最多显示**三个色点**；第四种及以后的颜色仍会被记录、侧栏也计入，只是行上看不到。
- 标签、收藏、工作区暂不支持**一键全部导出/导入**（标签库已支持）。
- 地址栏**只认目录**，输入文件路径不会打开它。
- Windows 10 兼容性、8 小时跑满时长、断网场景三项验收未跑完，本版不对相应指标作承诺；
  具体缺口见 [CHANGELOG.md](CHANGELOG.md) 的「1.0 已知限制」。

更细的取舍与原因见 [CHANGELOG.md](CHANGELOG.md) 与 [docs/backlog.md](docs/backlog.md)。
